# Campux-Reviewer — Campux 稿件审核助手

> 校园墙稿件审核助手（AstrBot 插件）。审核群内发送 `//bot <稿件id>`，自动读取该稿件通知内容、联网检索相关信息，并按该群绑定的稿件规则给出**通过/拒绝建议、判定原因及发布影响**。

配合 [Campux](https://github.com/idoknow/Campux) 校园墙使用的 AstrBot 审核插件。
在**审核 QQ 群**里发送 `//bot 稿件id`，插件自动：

1. 按群号找到该群**绑定的稿件规则**（一个审核群 ↔ 一套规则）；
2. 从本群早前收到的 **Campux 审核通知**中取出稿件正文与元信息；
3. **联网检索**稿件内容相关信息；
4. 调用大模型按规则判定，输出 **通过 / 拒绝 建议 + 原因 + 发布影响**。

## 安装

把本目录放到 AstrBot 的 `data/plugins/astrbot_plugin_campux_review/` 下，
在 WebUI → 插件 页面重载即可。

**联网检索**：用 **AnySearch 接口**（零依赖，标准库实现）。
请求地址与格式已内置在插件里，**你只需在配置页填 API Key**
（[https://anysearch.com](https://anysearch.com) 注册后在控制台创建）。
服务器上无需安装任何包。填写后，插件会拿**稿件正文**去检索——用于核实
稿件里没有明说的时事、热梗、地域/事件信息。

## 配置（WebUI → 插件 → 配置）

| 配置项 | 说明 |
| --- | --- |
| 触发指令前缀 | 默认 `//bot`，即 `//bot 5555` |
| 审核时联网搜索 | 开关，关闭则跳过检索 |
| **搜索 API Key** | **必填**。AnySearch 的 API Key，[点此获取](https://anysearch.com)（注册后在控制台创建）。请求地址与格式已内置，无需填写 |
| 联网搜索结果条数 | 每次检索抓取条数，默认 5 |
| 审核用大模型 | 留空用当前会话默认模型，也可指定 provider |
| 回溯消息条数 | 查找通知时向前回溯的群消息条数，默认 30 |
| 稿件缓存保留时长 | 缓存 TTL（小时），默认 72（3 天），超时自动清理 |
| 单群缓存稿件上限 | 每群最多缓存条数，默认 50，超出淘汰最旧 |
| 缓存群数量上限 | 最多缓存多少个群，默认 50，超出淘汰最久未活动 |
| **稿件规则** | 规则列表，每条 = 一个**审核 QQ 群号** + 该群使用的**规则文本**，一一对应 |

「稿件规则」是 `template_list`：点“添加”，选“规则 - 审核群 对应项”，
填 `审核 QQ 群群号`、可选 `校园墙名称`、以及 `稿件规则` 正文。

## 资源占用 / 缓存清理

稿件通知是内存缓存（因为插件拿不到群历史消息）。为**避免大量长时间占用资源**，
插件做了四重约束 + 主动清理：

1. **TTL 过期**：超过「稿件缓存保留时长」（默认 72h / 3 天）的条目自动失效；
2. **单群上限**：每群最多 50 条，超出淘汰最旧；
3. **群数上限**：最多 50 个群，超出淘汰最久未活动的群；
4. **正文截断**：单条正文超过 2000 字自动截断。

此外插件加载后会起一个**每小时**运行的后台清理任务，主动删除过期缓存；
插件卸载（terminate）时**取消清理任务并清空全部缓存**。四项上限均可在配置页调整。

## 使用

1. Campux 在审核群推送稿件通知（格式如下）；
2. 插件被动缓存该通知的内容；
3. 在群里发 `//bot 6928` → 返回审核建议。

### Campux 审核通知格式（插件据此解析）

```
📮 xx中学校园墙 新稿件
编号：#6928
投稿人：匿名（QQ 257xxxxx0）
来源：网页投稿
图片：0 张

今天初一二班中午在三楼排煮粉的那几个男生想干嘛 别人不用吃了吗 插个队还那么理直气壮

通过：#通过 6928
拒绝：#拒绝 <理由> 6928
```

其中 `今天初一二班…理直气壮` 是**稿件正文**，`6928` 是**稿件 id**。

## 注意

- 插件只能记住**自己加载之后**在群里收到的通知。若刚装好插件，
  请让稿件**重新通知一次**再触发审核。
- 审核结果仅供人工参考，最终通过/拒绝由审核员确认。
- OneBot 适配器会 strip 首尾空白，插件用零宽空格（`\u200b`）保护输出格式。
